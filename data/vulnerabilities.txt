#  HOW TO ADD A RECORD

#   2. Paste it at the end of the file and change the values.

#  RULES
#   - Lines starting with # are comments and are ignored.
#   - Lists (Models, Firmware, Ports, Protocols, Keywords) are comma separated.
#     Use * for "any firmware".   Firmware may use wildcards: V5.5.*
#   - MATCHING RULE: a scanned device is flagged only when its EXACT model is
#     listed in Models AND its firmware is consistent with Firmware (* = every
#     version). Records with Models * or a series pattern (e.g. DS-2CD2*) never
#     match — list each affected model by its full name. If a device's firmware
#     is unknown and the record names a firmware range, the match is reported as
#     UNVERIFIED (potential), never as a confirmed vulnerability.
#   - Severity: Critical | High | Medium | Low | Informational
#       Risk Score must fit: Critical 30-40, High 20-29, Medium 10-19, Low 1-9, Informational 0
#   - Source:  SIMULATED | COMMUNITY_REPORTED | VENDOR_ADVISORY | CVE
#       (use CVE only with the real CVE id as ID, e.g. CVE-2021-12345)
#   - Device Type: camera | nvr | dvr | any   (CCTV equipment only)
#   - Dates: YYYY-MM-DD.   Set Updated to today's date when you change a record.
#   - Steps: one "- " line per step (or:  Steps: step one | step two).
#   - Reference is optional (an https:// link). Match Fields is optional.
#   - Never put exploit code, passwords or attack instructions in a record.

ID: SXV-2026-0001
Title: HTTP-Only Interface on DS-2CD2 series cameras
Vendor: Hikvision
Models: DS-2CD2043G0-I, DS-2CD2143G0-I
Firmware: V5.5.*
Device Type: camera
Category: HTTP-Only Interface
Severity: Medium
CVSS: 5.3
Risk Score: 14
Ports: 80
Protocols: HTTP
Keywords: hikvision, http only, no tls
Source: SIMULATED
Published: 2025-09-01
Updated: 2025-09-08
Description: The web management interface is served over unencrypted HTTP, so credentials and session tokens can be observed by anyone able to capture traffic on the network path. Scope: Hikvision DS-2CD2043G0-I, DS-2CD2143G0-I. Affected firmware: V5.5.*.
Recommendation: Enable HTTPS for the management interface and redirect or disable plain HTTP.
Steps:
- Enable HTTPS in the device network or security settings.
- Install a certificate issued by an internal CA where possible.
- Disable the plain HTTP listener or redirect it to HTTPS.
Note: SIMULATED record created for academic demonstration. It is not a confirmed vulnerability in the named product.
